# Security policy

## Reporting a vulnerability

Maintainers must enable GitHub private vulnerability reporting in the repository settings before accepting public contributions. Once enabled, use **Security → Advisories → Report a vulnerability** to send a private report. Do not open public issues for security bugs. Never include real tokens, API keys, or student data in a report.

If the private reporting form is unavailable, do not post vulnerability details publicly. Ask the maintainers for a private reporting route first.

Scope: this bot's handling of your model key, agent token, network requests and model output.
